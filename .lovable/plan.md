## Что меняем

### 1. Логотип в одну строку
В `src/components/Header.tsx` убираем мобильный вариант с `<br/>` и оставляем единый `<span className="whitespace-nowrap">Ставропольский Перепел</span>`. На очень узких экранах слегка уменьшаем кегль (`text-base sm:text-lg`), чтобы влезало без переноса.

### 2. Птенец ходит по всей шапке
Сейчас `Mascot` живёт в `div h-11 w-11` рядом с логотипом — двигаться может только в ±70px от центра этого контейнера. Меняем архитектуру:

- В `Header.tsx` оборачиваем верхнюю строку в `relative` и добавляем оверлейный «трек» по всей ширине `max-w-6xl` шапки:
  ```text
  <div class="absolute inset-x-4 top-0 bottom-0 pointer-events-none" data-mascot-track />
  ```
  Птенец рендерится внутри этого трека, абсолютно спозиционирован (`left: pos px`), `pointer-events:auto` только на самой кнопке.
- В `Mascot.tsx`:
  - `containerRef` теперь измеряет ширину родительского трека через `ResizeObserver`, и `target` выбирается из диапазона `[16, trackWidth - 56]` (с отступом, чтобы не залезать на бургер/телефон).
  - На стадиях `egg/wobble/crack-*/peek` птенец/яйцо стоит у левого края (около логотипа). После `hatched` начинает гулять по всей доступной ширине.
  - На моб. вьюпорте трек тоже на всю ширину строки шапки — гуляет так же.

### 3. «Остановился и поднял крыло» + минималистичная подсказка
- В `MascotProvider` убираем автопоказ подсказки по таймеру `1200ms` после смены роута. Вместо этого подсказка показывается, когда птенец **достигает цели и останавливается** (событие из `Mascot`).
- В `Mascot.tsx`:
  - Когда `dist < 1` и был `moving=true` → вызываем `onStop()`. С вероятностью ~70% (или каждые N остановок) запускаем `showTip()` и поднимаем крыло (новый стейт `wingRaised`, который меняет `d` пути крыла на «поднятое» + лёгкий поворот).
  - Крыло возвращается обратно при `hideTip` или через 7s.
  - Клик по птенцу по-прежнему форсит подсказку.
- Простоявший без подсказок интервал `idleTimer` (18–28s) оставляем как fallback.

### 4. Подсказка не обрезается
Сейчас бабл — `absolute left-1/2 top-full` внутри маленького контейнера → обрезается шапкой/краем вьюпорта.

Перерисовываем `SpeechBubble` через `createPortal(document.body)` с `position: fixed`:
- Позиция считается из `headRef.current.getBoundingClientRect()`: `top = rect.bottom + 10`, `left = clamp(rect.left + rect.width/2 - bubbleW/2, 8, window.innerWidth - bubbleW - 8)`.
- Хвостик бабла абсолютно позиционируется по `rect.left + rect.width/2 - left`, чтобы всегда «торчал» из птенца, даже после клампа к краю экрана.
- Размеры: `max-w-[min(260px,calc(100vw-16px))]`, `text-xs`, 1–2 строки + кнопка CTA. Отступы уменьшаем (`px-3 py-2`), радиус `rounded-2xl`, тонкая граница, мягкая тень — минимализм.
- Пересчёт позиции на `scroll`/`resize`/смене `pos` птенца (через `requestAnimationFrame` пока бабл открыт), чтобы бабл «следовал» за птенцом, как держал бы его в крыле.

### 5. Reduced motion
Без изменений: птенец сразу `hatched`, не ходит, бабл показывается статично у левого края шапки (фиксированная позиция от логотипа).

## Технические детали

Файлы:
- `src/components/Header.tsx` — логотип в одну строку, `relative` контейнер, оверлей-трек для маскота.
- `src/components/mascot/Mascot.tsx` — измерение ширины трека, диапазон `target`, `wingRaised`, событие `onStop`, `SpeechBubble` через `createPortal` с fixed-позицией и clamp.
- `src/components/mascot/MascotProvider.tsx` — убрать автопоказ tip по route-change таймеру; оставить idle-fallback и метод `showTip` для внешнего вызова из `Mascot` при остановке.

Без новых зависимостей. Логику стадий по скроллу не трогаем.

## Acceptance
- На десктопе и мобилке птенец после вылупления гуляет по всей ширине шапки (от логотипа до правого края, без наложения на бургер/кнопки).
- Подсказки появляются только когда птенец остановился; визуально — минималистичный белый бабл с хвостиком вверх, у птенца поднято крыло.
- Бабл никогда не обрезается: на узком экране автоматически смещается, оставаясь в пределах вьюпорта.
- Логотип «Ставропольский Перепел» — одной строкой на всех брейкпоинтах, без переносов.
