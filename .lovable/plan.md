## Контекст проверки

Снял скриншоты при 320×600 и 375×700:
- 375px — заголовок умещается с большим запасом, ниже него полоса чипов прокручивается горизонтально.
- 320px — заголовок умещается полностью (≈250px текста при 288px внутреннего места после `px-4`), запас справа ≈30px. Переноса нет (`whitespace-nowrap`), обрезания тоже нет, но запас тонкий.
- 320–480 — переносов и обрезаний нет.

Чтобы прибавить устойчивости (мелкие Android-устройства типа 320–360, и чтобы шиммер не упирался в правый край), внесу две минимальные правки в `src/components/Header.tsx`:

### Правка 1 — компактнее горизонтальные отступы на мобильном

Контейнер шапки сейчас:
```
<div className="relative mx-auto max-w-6xl px-4">
```

Меняю на адаптивный паддинг:
```
<div className="relative mx-auto max-w-6xl px-3 sm:px-4">
```

Это даёт +8px ширины внутри шапки на ≤640px. Заголовок получает ≈40px суммарного запаса при 320px вместо ≈30px. Десктоп и контент остальных страниц — не трогаются (паддинг основного контента живёт внутри страниц, не в `<Header>`).

Полоску чипов под треком тоже подровняю:
```
-mx-4 px-4 → -mx-3 sm:-mx-4 px-3 sm:px-4
```
чтобы её «вытягивание под full-bleed» совпадало с новым паддингом контейнера и не появлялась горизонтальная полоса прокрутки у `<header>`.

### Правка 2 — мини-фолбэк размера шрифта на самых узких

Чтобы исключить обрезание даже при системных шрифтовых увеличениях/iPhone SE (320), добавлю промежуточный размер:
```
text-[18px] xs:text-[19px] sm:text-2xl
```

В этом проекте кастомного `xs` нет, поэтому проще через явный медиа-класс Tailwind v4 либо arbitrary variant. Чище — через arbitrary media:
```
text-[18px] [@media(min-width:360px)]:text-[19px] sm:text-2xl
```

Это даёт «−1px» только на устройствах ≤359px (iPhone SE 1, старые Android), а на 360+ остаётся текущий 19px. Гарантия отсутствия обрезания.

### Что НЕ трогаем

- Шрифт, жирность, межбуквенные интервалы.
- Анимацию `title-shimmer` и побуквенный fade-in.
- Полосу чипов (порядок ссылок, цвета, скругление).
- Десктоп.
- Маскота.

### Затрагиваемые файлы

- `src/components/Header.tsx` — `px-3 sm:px-4` на контейнере, `-mx-3 sm:-mx-4 px-3 sm:px-4` на полосе чипов, размер шрифта заголовка с фолбэком 18px ниже 360px.

### Проверка после правки

- Скриншоты при 320×600, 360×640, 375×667, 414×896, 480×800 — заголовок целиком виден, переносов нет, чипы прокручиваются, header не имеет горизонтального скролла.
