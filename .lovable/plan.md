## Раздел «Корм для перепелов» — /korm

Новая категория верхнего уровня, рядом с Яйцами, Птицей, Мясом, Сопутствующими и Клетками.

### Структура

Хаб-страница `/korm` со списком подкатегорий + общим описанием:
- Собственное производство, без накруток
- Готовим, фасуем и продаём
- Возможна брендированная упаковка под заказ

Подкатегории (на старте — одна, архитектура расширяемая):
- `/korm/startovyy` — Стартовый комбикорм для молодняка (0–3 нед.). Высокобелковый, для цыплят перепелов.

### Контент подкатегории «Стартовый»

- Hero + хлебные крошки
- Описание: назначение, возраст птицы, состав (зерновые, белковая часть, премикс), польза для роста
- Карточки фасовок (PackagingCard) — без цен, «Цена по запросу» / «Уточняйте по телефону»: мешок и розничная упаковка
- Опция брендирования упаковки под заказ
- HowToOrder, FaqAccordion (3–4 вопроса: хранение, состав, минимальный заказ, доставка), FinalCta
- SEO `head()` + `BreadcrumbList` JSON-LD

- Подкатегории «Ростовой», «Для несушек», «Брендированный фасованный» — не добавляем (пользователь выбрал только «Стартовый»). Структура останется готовой для расширения.
- Цены не указываем — везде «Цена по запросу».
