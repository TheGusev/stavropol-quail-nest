## Правка `PageHero` (`src/components/PageHero.tsx`)

Сейчас, когда у `PageHero` есть `image`, текст оборачивается в белую карточку (`bg-card/85`, `backdrop-blur-md`, `rounded-3xl`, `shadow-xl`), которая закрывает фоновое изображение. Это и есть «спрятанные картинки».

**Что делаю:**

1. Убираю обёртку-карточку полностью. Никаких `bg-card/85`, `backdrop-blur`, `border`, `shadow-xl`, `rounded-3xl`, `px-5 py-5` вокруг текста. Текст рендерится напрямую как при варианте без картинки.
2. Картинка остаётся фоном (`absolute inset-0 -z-10 object-cover`) и видна полностью.
3. Чтобы текст оставался читаемым поверх фото, добавляю мягкий градиентный оверлей на всю секцию (только когда есть `image`): `absolute inset-0 -z-10 bg-gradient-to-r from-background/80 via-background/50 to-transparent`. Это не «коробка вокруг текста», а лёгкая вуаль на фоне — картинка по-прежнему видна, особенно справа.
4. Убираю `max-w-2xl` ограничение, которое было только внутри карточки — текст просто живёт в общем контейнере `max-w-5xl`.
5. Анимации `animate-fade-in` для kicker / h1 / lead сохраняю.

**Файл:**
- `src/components/PageHero.tsx` — удалить условную обёртку с карточкой, добавить градиентный оверлей поверх фонового изображения.

**Где это применится автоматически (ничего больше не трогаю):**
`/myaso-perepela`, `/o-ferme`, `/sertifikaty`, `/perepelinye-yaytsa`, `/inkubatsionnoe-yaytso`, `/molodnyak`, `/dostavka`, `/opt`, `/kontakty`, гео-страницы и любые другие, где `PageHero` получает `image`.

- Открыть `/myaso-perepela` и `/o-ferme` на мобилке (393px) и десктопе — картинка видна целиком, текст без белого блока, читается за счёт градиента слева.
