
## 1. Маскот на мобильной версии — в нижнюю панель

**Файлы:** `src/components/mascot/Mascot.tsx`, `src/components/mascot/MascotProvider.tsx`, `src/components/MobileBottomBar.tsx`

- На мобилке (`< 768px`) маскот (яйцо + цыплёнок + подсказки) больше не «гуляет» по верху страницы. Он живёт внутри `MobileBottomBar` — встраивается в ту же панель, где WhatsApp / Позвонить / Каталог, как четвёртая «зона» или как фоновый слой над панелью.
- Цыплёнок ходит по ширине нижней панели (поле движения = ширина `MobileBottomBar`, высота = высота панели + небольшая зона над ней для прыжков/подсказок).
- Подсказки (тексты) появляются над панелью, привязаны к позиции цыплёнка, с тем же правилом «появляться только если хватает места» (без выезда за правый край вьюпорта).
- На десктопе/планшете (`≥ 768px`) — поведение как сейчас (ходит сверху над хедером, без изменений).
- **Скорость возвращаем к исходной**: `speed = 46` px/sec, walk phase `dt * 9`, интервал смены цели `4500 + Math.random() * 3500` (откатываем замедление).
- Анимации яйца/цыплёнка и тексты подсказок не трогаем — те же реплики, те же переходы.

**Технически:** `MascotProvider` определяет `isMobile` через `matchMedia(max-width: 767px)` и рендерит маскот либо в текущий портал (десктоп), либо внутрь `MobileBottomBar` (мобилка) через отдельный портал-контейнер. `MobileBottomBar` получает `position: relative` и слот сверху для подсказок (`overflow: visible` для всплывающих текстов).

**Новый файл:** `src/routes/kletki.tsx` (URL `/kletki`)

## Что не меняется
- Логика подсказок (правило «текст не выезжает справа») — та же.
- Поведение хедера, бургер-меню, `PageHero` (без карточки, с градиентом) — без изменений.
- Десктопная позиция маскота — без изменений.
