## Цель
Сделать шапку на мобайле компактной и аккуратной, упростить подсказку маскота (без «облачка», в одну строку), увеличить яйцо и спрятать его при включённом prefers-reduced-motion, а также добавить безопасный fallback, если `data-mascot-*` ещё не отрисовались или шапка меняет размер.

## 1. Шапка — компактная мобильная версия (`src/components/Header.tsx`)

Убираю с мобильного верхнего ряда кнопки «Позвонить» и «WhatsApp» — они выглядят перегружено. Оставляю только бургер.

- **Мобильный верхний ряд**: только иконка-бургер справа (`h-9 w-9`, без бордера/фона). Звонок и WhatsApp полностью убираются с верхней панели.
- **Бургер-меню (открытое)**: добавляю туда кнопку «Позвонить {номер}» и крупную WhatsApp-кнопку — теперь это единственное место их вызова на мобайле.
- **Логотип-ряд**: уменьшаю верхний отступ трека (`pt-10` → `pt-7`), чтобы шапка стала ниже. Шрифт логотипа на мобиле оставляю крупным, но `leading` чуть плотнее.
- Десктоп (`lg:`) не трогаю — кнопки остаются на месте.

Итог: мобильная шапка превращается в две короткие линии (бургер сверху, логотип снизу) — становится заметно ниже и аккуратнее.

## 2. Подсказка маскота — без облачка, одна строка (`src/components/mascot/Mascot.tsx`)

Полностью переписываю `SpeechBubble` → `MascotTip`:
- Убираю карточку (`bg-card`, бордер, тень, скругление, паддинги, стрелку).
- Остаётся только текст: один `<span>` с `whitespace-nowrap`, `text-foreground`, `text-[12px]/4 font-medium`, тень `drop-shadow-sm` для читаемости поверх фона.
- **Одна строка, никаких переносов**: `whitespace-nowrap` + `max-w-[min(60vw,260px)]` + `overflow-hidden text-ellipsis` — не растягивает шапку, длинный текст обрезается с многоточием.
- Без кнопки «×» и без CTA-кнопки внутри подсказки (CTA убираем из визуала — он есть в основной шапке/блоках страницы). Авто-скрытие через 7 сек уже работает в Provider.
- Позиционирование оставляю фиксированным к птенцу (`getBoundingClientRect`), но без стрелки и без переключения арки. Просто текст справа от птенца, при нехватке места — слева. Вертикально по центру птенца, с clamp-ом в пределах `<header>`.
- Печатной анимации (typewriter) больше нет: текст появляется сразу с лёгким fade-in (`opacity 0→1, 180ms`), при `reducedMotion` — без анимации.

## 3. Яйцо — крупнее и без «таскания» (`src/components/mascot/Mascot.tsx`)

- Увеличиваю SVG-яйцо: `width 34→44`, `height 40→52`, обновляю `EGG_W = 44`. Виднее и приятнее.
- Чтобы оно не «таскалось мелким» по экрану всё время: при `reducedMotion` яйцо вообще не рендерится — стартуем сразу со стадии `hatched` (это уже делает Provider, надо лишь убедиться, что условие `stage !== "hatched"` действительно прячет egg-блок — оно прячет; добавлю явный guard `&& !reducedMotion`).
- Лёгкий «дрожащий» бэйслайн: убираю авто-rolling из вращения вне фактического движения — `rolling` считаю только когда `eggProgress` реально меняется (если стадия `egg`/`wobble` без скролла — angle = 0).

## 4. Безопасный fallback для `data-mascot-*` и ресайза шапки

В `Mascot.tsx` сейчас `layout.ready` ставится только когда найдены **все 5** якорей. Если хотя бы один отсутствует (например, шапка не на странице или DOM ещё не готов), маскот не рендерится вовсе — это нормально, но добавляю явную защиту:

- Если в течение **1.5 сек** хоть один из `data-mascot-*` не найден — переключаемся в «безопасный режим»: 
  - Egg/Chick **не рендерятся** (возврат `null`).
  - Подсказка тоже скрывается (без anchor некорректна).
  - В консоль — `console.warn` один раз.
- На ресайз/смену шрифта/изменение ширины: уже есть `requestAnimationFrame`-цикл в `measure`, но он бесконечный и греет CPU. Заменяю его на:
  - Один начальный замер.
  - `ResizeObserver` на `track` и `header`.
  - `window` events: `resize`, `orientationchange`, `load`, `fontfaceset` (при готовности шрифта).
  - Throttle через `requestAnimationFrame`.
- Жёсткий **clamp** позиций птенца и яйца к границам трека (`Math.max(0, Math.min(layout.trackW - CHICK_W, x))`) — даже если измерения невалидны, маскот не «улетит».
- Проверка `layout.eggEndX > layout.eggStartX` и `walkMax > walkMin` перед использованием; иначе fallback-режим.

## 5. prefers-reduced-motion — максимальное упрощение

Provider уже выставляет `hatched` сразу. Доуточняю в `Mascot.tsx`:
- При `reducedMotion`:
  - Птенец стоит неподвижно у `eggEndX` (без walk-loop, без jump, без bob, без blink, без chirp — почти всё уже учтено, добавляю явный early-return из `walk loop` и `jump`).
  - Яйцо не рендерится вообще.
  - Подсказка появляется без анимации, без typewriter, висит 7 сек, с обычным fade-out.
  - Никаких бесконечных rAF-циклов на измерения (используем ResizeObserver, см. п.4).
- В `Header.tsx`: для `reducedMotion` отключаю stagger-анимацию букв логотипа (через `useReducedMotion()` из framer-motion).
