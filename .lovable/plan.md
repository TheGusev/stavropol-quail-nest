## Правки

### 1. Подсказка — без выезда справа (`MascotTip` в `src/components/mascot/Mascot.tsx`)

Сейчас при длинном тексте включается marquee и текст «выезжает» справа. Меняю логику:

- **Marquee убираю полностью.** Текст показываем только если он целиком помещается в доступной справа/слева от птенца зоне в верхней полосе шапки.
- Алгоритм:
  1. Замеряю ширину текста через скрытый `<span>` с теми же стилями (off-screen `visibility: hidden`).
  2. Считаю свободное место: `rightSpace = innerWidth - chickRect.right - 12`, `leftSpace = chickRect.left - 12`.
  3. Если `textWidth <= rightSpace` → показываю справа (fade-in, без движения).
  4. Иначе если `textWidth <= leftSpace` → показываю слева.
  5. Иначе — **подсказку не показываем вообще** (тихо `hideTip()` в провайдере, чтобы не висел невидимый tip и таймер сбросился). При следующей остановке/клике попробует снова.
- На очень узких экранах, где даже короткий tip не помещается — просто не показываем.
- Никаких `overflow: hidden`, никакой анимации `x`, никакого `repeat: Infinity`.

### 2. Бургер над «л» — только мобилка (`src/components/Header.tsx`)

Сейчас `MenuButton` рендерится всегда и абсолютно позиционируется поверх буквы «л» — на десктопе он залазит на название.

- Добавляю в `MenuButton` проверку viewport через `window.matchMedia("(max-width: 1023px)")` (lg breakpoint Tailwind).
- Если desktop (`>= 1024px`) — компонент возвращает `null`, на якорь не подписывается, ResizeObserver не создаёт. Слушаю изменение mq для переключения при ресайзе.
- Класс `lg:hidden` оставляю как страховку, но основная защита — ранний `return null`.
- Также в `Mascot.tsx` фикс: `menuLeft/menuRight` считаются только если кнопка реально найдена в DOM (она и так условно рендерится — нужно проверить, что layout при отсутствии кнопки не блокирует обход; сейчас `menuLeft = menuRight = 0`, `mR > mL` ложь — обход выключен, что корректно для десктопа).

### 3. Птенец медленнее (`src/components/mascot/Mascot.tsx`)

- В walk loop меняю `const speed = 46` → `const speed = 22` (px/sec) — почти в 2 раза медленнее.
- Замедляю частоту шагов: `setWalkPhase((w) => w + dt * 9)` → `dt * 5` — лапки моргают спокойнее.
- Реже выбирает новую цель: интервал `4500 + Math.random() * 3500` → `7000 + Math.random() * 5000`.
